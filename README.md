# ICT205 Weekly Practical Portfolio

This repository contains the weekly practical work completed for the ICT205 Mobile Application Development unit.

Each practical is stored in a separate folder with its Flutter source code, documentation, testing evidence and screenshots.

## Completed Practicals

### Practical 1 – Flutter Installation and Setup

This practical covers:

- Git, Flutter and Dart verification
- Android Studio and Android SDK configuration
- Android emulator setup
- Visual Studio Code Flutter and Dart extensions
- Creation and execution of the first Flutter application
- Counter application functionality testing

Folder:

`Prac_01_Flutter_Installation`

### Practical 2 – Discount Calculator

This practical covers:

- Separate Dart business logic
- Flutter user-interface integration
- Original-price and discount input
- Discount calculation
- Input validation and error handling
- Successful and invalid-input testing

Folder:

`Prac_02_Discount_Calculator`
